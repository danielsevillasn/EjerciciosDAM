Para ejecutar este proyecto en el IDE eclipse

Proyecto formado por dos aplicaciones.
- Lanzador. Con código en ficheros Lanzador.java, HiloAtiendeProceso.java, Monitor.java
- Proceso-Hijo. EjerCompleto2.java

Aunque tratándose de dos aplicaciones lo normal es hacer dos proyectos diferentes. Para pruebas puedes incluir ambos en un único proyecto Eclipse.

Distribución de los ficheros dentro de un poryecto Eclipse.
- Crear un único proyecto y meter los cuatro ficheros .java en el paquete por defecto.
- Poner el fichero archivo.txt en la ruta del proyecto. Directorio que tiene los directorios src y bin.
- Poner el resto de ficheros .txt en el directorio bin.

El ejercicio responde al enuciado disponible en la colección de ejercicios del tema 1. Ejercicio avanzado. Añadiendo que la comunicación con 
diferentes procesos se hace de forma simultánea mediante hilos. Se adjunta el enunciado en el fichero Tema1-Ejercicio-01.pdf
